# Road to 30

A single-page Turkey Trot 5K training dashboard.

## What it tracks
- planned vs. actual workouts
- mileage progression
- continuous-run pace trend
- heart-rate trend
- treadmill, stroller, and solo-outdoor context
- badges, XP, mileage clubs, and progress milestones
- manual run entry and Strava CSV import

## Data note
This version stores data in the browser's local storage. Use the built-in Backup/Restore tools to move or preserve your run log.

## Publish with GitHub Pages
In this repository, go to **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/ (root)**, then save.
